2. Regras de Negócio e Comunicação (Invariantes)
CLP: Fertron Citrino FX.

Comunicação: Modbus/TCP, Porta 502, Unit ID 255, Função 03.

Endereçamento: 0-based. O endereço no CSV (FP:X ou 4X:Y) deve ser subtraído em 1 para a leitura (address: X - 1).

Tipos de Dados:

Analógicos (FP): Float32, 2 registradores, ordem de palavras trocadas (CDAB).

Digitais/Bits (WM ou 4X com bit): 1 registrador, ler a palavra inteira e extrair o bit via deslocamento (>> e & 1).

Polling: 5 segundos por ciclo.

3. O "Padrão de Ouro" (Node-RED Validado)
Após vários testes com timeouts (ECONNRESET, Timed out, queue cleared), a arquitetura que se provou 100% estável foi:

Leitura Individual: 1 nó modbus-flex-getter para cada variável (não agrupar em blocos grandes).

Injetores Escalonados: Os injetores disparam a cada 5s, mas com onceDelay defasados (ex: 0.1, 0.4, 0.7...). Isso evita sobrecarga na fila do CLP.

Decodificação (Float32 CDAB):

javascript
const reg_low  = msg.payload[0];
const reg_high = msg.payload[1];
const buf = Buffer.alloc(4);
buf.writeUInt16BE(reg_high & 0xFFFF, 0);
buf.writeUInt16BE(reg_low  & 0xFFFF, 2);
const val = buf.readFloatBE(0);
Envio para o InfluxDB 3:

Measurement: plc_data

Tag: plc: 'NomeDoSetor' (ex: Moenda ou 228)

Payload Format:

json
msg.payload = {
    fields: { [msg.topic]: val },
    timestamp: Date.now()
};
